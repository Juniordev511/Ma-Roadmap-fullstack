## ✅ Phase 1 — HTML (terminé)

4 projets pratiques réalisés pour maîtriser la structure sémantique HTML :
titres, sections, tableaux, formulaires et accessibilité de base.

| Projet                      | Description                                                                                      | Dossier                     |
| --------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------- |
| 📝 Page de blog             | Article complet avec en-tête, citation, points clés, commentaires et formulaire                  | `phase-1-html/blog/`        |
| 👤 CV / Portfolio           | Page CV en ligne avec navigation par ancres, formation en tableau et formulaire de contact       | `phase-1-html/cv/`          |
| 🛒 Fiche produit e-commerce | Présentation produit avec caractéristiques techniques, avis clients et bouton d'achat            | `phase-1-html/produit/`     |
| 📋 Formulaire d'inscription | Formulaire complet couvrant tous les types de champs HTML (radio, checkbox, select, fieldset...) | `phase-1-html/inscription/` |

**Notions travaillées :**

- Structure sémantique (`header`, `nav`, `main`, `article`, `section`, `footer`)
- Hiérarchie de titres cohérente
- Tableaux de données (`table`, `thead`, `tbody`)
- Formulaires complets (`label`, `fieldset`/`legend`, tous types d'`input`, `required`)
- Accessibilité de base (`alt`, labels associés)
- Validation W3C
